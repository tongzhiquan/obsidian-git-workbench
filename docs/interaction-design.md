# 工作台交互设计

更新：2026-10-21。

## 当前导航

工作台使用一个 Obsidian 标签，通过内部导航切换提交图、笔记历史、版本比较、分支与标签、Stash。提交详情显示在图右侧；冲突处理从变化文件进入。

源代码管理默认显示在右侧栏。标题栏按钮依次为布局、刷新、过滤、工作台、更多；更多菜单保持最右，并提供布局、笔记库过滤及工作台入口。过滤同步作用于列表、计数和批量暂存范围。重复打开工作台或侧栏时复用已有标签。

## 保存约定

工作文件保存、暂存和提交是独立操作。比较器显示未保存标记，使用工具栏按钮或 Ctrl/Cmd+S 保存到明确目标；重新加载前确认是否放弃编辑。

未保存内容只在当前会话保留，不写入插件配置。历史恢复、Stash 和覆盖前的内部安全副本各自保留原有用途；不提供独立草稿管理或恢复备份页面。

差异布局、行操作和编辑权限见 [差异比较设计](line-staging-and-revision-selection.md)，使用步骤见 [README](../README.md)。
