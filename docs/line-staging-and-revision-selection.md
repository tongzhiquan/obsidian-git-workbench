# 差异比较设计

更新：2026-10-21。本文记录已实现的交互约定；后续导航方案见 [工作台交互设计](interaction-design.md)。

## 操作范围

| 比较                        | 行操作             | 写入目标                         |
| --------------------------- | ------------------ | -------------------------------- |
| 暂存区 → 工作区             | 左侧还原，右侧暂存 | 还原写工作文件；暂存写暂存区     |
| HEAD → 暂存区               | 取消暂存           | 暂存区                           |
| 首次提交前的空版本 → 暂存区 | 取消暂存           | 暂存区                           |
| 其他版本组合                | 不提供行暂存或还原 | 文本保存按右侧目标的编辑权限处理 |

还原将对应工作文件内容恢复到暂存区版本，执行前确认范围。暂存和取消暂存不改变工作文件，所有行操作均不创建提交。

新增、删除普通文本文件支持部分暂存；全部删除或全部取消新增文件的暂存时，移除对应索引项。二进制、大文件、冲突、重命名、文件模式变化、自定义过滤或编码转换、混合换行不提供行操作；计算超过行模型限额时也保留文件级操作。

## 行布局与选择

- **并排模式**：按钮位于行号旁；左侧还原、右侧暂存。另一侧没有内容时，在空白占位行提供对应入口。
- **统一模式**：红色旧行提供还原，绿色新行提供暂存；纯新增或纯删除在实际存在的行上同时提供两个动作。
- **已暂存比较**：动作统一命名为“取消暂存”，与工作文件还原区分。

按钮支持悬停说明、Tab 聚焦和 Enter 执行，操作栏宽度固定。行旁按钮只处理对应修改；选区或行号选择的多行，通过按需显示的操作条或右键菜单处理。Shift+点击行号连续选择，不选择未修改行。

两个模式共用 `line-edits` 模型。连续变更按顺序对应旧行和新行，替换行作为一处修改，多出的行为独立新增或删除。范围以完整逻辑行计算，选区终点位于下一行开头时不包含下一行；不支持字符级暂存。

## 编辑权限与版本输入

“允许编辑已暂存文件”默认关闭，控制已暂存文件的工作区和暂存区直接编辑；历史提交始终只读。该设置不禁用明确的暂存、取消暂存或还原操作。列标题显示通用“只读 / 可编辑”状态，权限开关及说明仅放在设置中。

有未保存编辑时，先保存或确认重新加载，再执行行操作或切换编辑权限。保存工作文件不自动暂存，保存暂存区不修改工作文件。

版本栏保留文件路径、左右版本输入及比较按钮，接受分支、标签、SHA、`HEAD`、`:index`、`:worktree`、`:empty`。`:index` 表示准备提交的暂存快照。当前不提供比较预设按钮、左右换位或搜索选择器；文件历史中的双版本选择继续可用。

## 写入与刷新

逐行写入进入仓库队列，获取真实 `index.lock` 后复查索引和文件快照。复制索引到临时文件，仅更新目标项，再原子替换；保留其他暂存项、模式及换行规则。局部还原也验证暂存基线，并复用工作文件的过期检测及 Vault 保存流程。外部变化或锁占用时拒绝旧操作，不扩大范围。

成功写入后，使用实际 blob 快照通过 CodeMirror 事务原地更新；统一模式同步更新原版本。保留编辑器、光标、滚动、折叠和版本输入，不生成未保存编辑。后续仓库状态与延迟监听刷新沿用当前实例；失败保留原差异，不兼容的类型、模式或换行变化才重建视图。

索引项一致时可复用不可变 blob，减少重复读取；旧代查询不得写入新代缓存。保存比较内容后重新计算行模型。验收结果见 [验证记录](../VALIDATION.md)。
