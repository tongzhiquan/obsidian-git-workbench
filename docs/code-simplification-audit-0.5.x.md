# 0.5.x 保守代码精简审查

日期：2026-10-30。基线：已发布的 0.5.0（`e723c88`）。审查与实施分支：`codex/code-simplification-0.5x`。

## 结论

可以做少量等价重构，优先集中重复的资源生命周期和范围判断；没有足够依据进行功能删减或大规模模块拆分。本轮保留设置、界面、错误提示和公开方法，不修改版本文件或 `src/types.ts`。

29 个 TypeScript 源文件按统一 LF、排除空行计数，重构前后均为 2,830 行；源码 UTF-8 字节数由 226,633 降至 226,143。净行数并非本轮主要收益，重点是让两条索引写入路径共用安装和清理代码、让三处块范围判断共用一处实现。新增回归测试和本文档单独计入，不作为源码精简量。

## 已实施的精简

| 位置 | 重复或冗余 | 处理及保留约束 |
| --- | --- | --- |
| `src/git/service.ts` | `saveIndex` 单独管理 index 锁；它与 `applyLines` 重复实现临时 index 安装和清理 | 新增私有 `withIndexUpdate`，共用现有仓库写队列与 `withIndexLock`，集中生成临时路径、写入/同步/关闭锁文件、原子替换及清理 |
| `src/ui/diff-actions.ts` | gutter 实际行、统一模式删除行 gutter、删除 DOM 同步分别查找所属修改块 | 新增私有 `blockAt`，统一左右逻辑行归属判断；空侧占位、块首尾和动作权限仍由原分支处理 |
| 差异块视图更新 | 装饰由 ViewPlugin 更新，DOM 范围同步另挂一个 update listener | 将同步调度移入现有 ViewPlugin 更新回调，保留初始化时的微任务、DOM 完成更新后的同步和销毁保护 |
| 插件入口、工作台 | 两处 `HEAD` 导入没有引用 | 只移除导入；额外启用编译器未使用符号检查确认没有其他此类诊断，不改项目编译配置 |

索引辅助函数仅复用生命周期。过期检查仍在持有真实 `index.lock` 后、复制 index 之前执行；调用方仍明确决定安装时机，`applyLines` 继续在安装后生成返回快照。暂存快照保存使用 `--no-filters`，逐行暂存保留 `--path` 的换行转换；空仓库 index 初始化、其他暂存项、文件模式与既有锁错误文案均保留。

## 核对后保留的候选项

| 候选 | 调用证据或差异 | 本轮决定 |
| --- | --- | --- |
| 旧 `applyHunk` 和 hunk 数据模型 | 生产界面已使用 `applyLines`，但 `applyHunk` 仍有 Git 集成测试调用，且是公开方法 | 保留；删除需另行确定接口兼容范围，不能按私有死代码处理 |
| 拆分 `main`、`GitService`、大型 UI 类 | 职责多，但拆文件本身不消除逻辑，跨文件状态与生命周期调整会扩大回归范围 | 暂缓，保持此次改动集中 |
| 合并编辑、暂存的可用性校验 | 混合换行、过滤器、模式、缺失文件等限制服务于不同写入目标，并非同一权限规则 | 保留各自约束；没有证明等价的条件不强行合并 |
| 统一缓存和视图刷新调度 | 仓库代数、在途刷新、未保存内容与 CodeMirror 布局各有独立时序要求 | 保留已有保护，不以减少标志字段为目标 |
| 逐行/按块及并排/统一布局的分支 | 空侧占位和删除 widget 不使用同一种文档坐标 | 只共享范围查找，不合并坐标映射与交互分支 |

除两处未使用导入外，未发现可由编译器和调用关系共同确认、适合本轮删除的私有实现。不新增依赖，不改变设置或公开类型。
